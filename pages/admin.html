Post Updates to the Live Site

Publish pop-up announcements that appear on the website as visitors scroll. Each update auto-removes itself when its time is up. Everything is stored in your GitHub repository — no server to maintain.

Step 1

Connect to your repository

Enter once. Saved to this browser only — never sent anywhere except GitHub. Use a fine-grained token scoped to just this one repo.

How to create the token — one time, 3 minutes
  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: Agape Updates Admin
  3. Expiration: 90 days (or "No expiration" if you accept the risk)
  4. Repository access: Only select repositories → tick just this one repo
  5. Permissions → Repository permissions → Contents: set to Read and write
  6. Click Generate token and paste it above.

Safety note: this token is scoped to a single repository with a single permission. Even if it leaks, the worst an attacker can do is edit files in this repo. Rotate it (delete and recreate) any time you suspect exposure.
